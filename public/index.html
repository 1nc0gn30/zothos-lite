⚡ What Happens When You Shut Off or Close the Machine?

            

              ZothOS Lite boots using the Debian Live toram noswap kernel flags. The entire operating system image is decompressed into your computer's volatile RAM memory at startup.
            

            

              Complete Physical Memory Discharge: Because volatile RAM requires continuous electrical power to retain state, the instant your machine is powered off, rebooted, or the battery is removed, every byte of data in memory is erased permanently.
            

            

              
# The Boot Media is Safe to Remove:
1. Boot the PC from your ZothOS Lite USB.
2. When the desktop appears, you can unplug the USB thumb drive.
3. The entire OS, desktop, and tools run 100% inside RAM.
4. On shutdown, 0 trace remains on the host PC.

            

            

              Internal hard drives (NVMe/SATA) remain untouched and unmounted by default. ZothOS never writes log files, browser history, or swap files to host disks.
            

          


          
          

            
💾 How to Save Your Work, Code & Agent Memories

            

              Because RAM clears on shutdown, you must save persistent work to external storage or cloud endpoints:
            

            
Option A: External USB Drives & SSDs (Recommended)

            

              
# 1. Plug in any formatted USB drive (exFAT, NTFS, ext4)
# 2. It will auto-mount under:
/media/zoth/<YourDriveName>

# 3. Store your Git repos, LLM checkpoints, and files directly on the drive.
# 4. Instant backup helper:
$ zoth-backup /media/zoth/MyUSB

            

            
Option B: Cloud Storage Synchronization (rclone)

            

              
# Configure Google Drive, AWS S3, Dropbox, or Nextcloud:
$ rclone config

# Mount your cloud storage directly into your home folder:
$ mkdir -p ~/CloudDrive && rclone mount mydrive: ~/CloudDrive &
